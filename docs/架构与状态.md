# 架构与状态

## 运行拓扑

```text
浏览器 ─HTTPS→ Nginx ─HTTP→ xcloud-server (:8082)
                              ├─ Auth：OIDC Authorization Code + PKCE
                              ├─ MySQL：实例与 MVP 业务表
                              ├─ Redis：服务端会话
                              ├─ RabbitMQ：部署任务队列
                              └─ HTTP + Bearer Token → xcloud-agent (127.0.0.1:13092)
                                                           └─ Docker xcloud_network → AlemonX (:17390)
```

用户实例不发布宿主机端口。访问 `xcloud-r<16位十六进制哈希>.alemonjs.com` 时，Nginx 将路由键传给 agent；agent 以 Docker 标签 `xcloud.route` 查找容器，通过 `docker inspect` 取得内部 IP 后反代到 17390。

## 已实现

- Auth 公共客户端的 PKCE 登录、HttpOnly 服务端会话与管理员权限判断。
- React 用户台原型、开发模式内置超级管理员、实例创建/启动/停止/删除 API。
- agent 的令牌校验、Docker 资源限制、数据卷、健康检查、内部网络与反向代理。
- MySQL 初始化：实例、平台设置、节点、镜像、套餐、订单、任务和审计日志表。
- Redis 会话存储、RabbitMQ 持久化队列声明，以及生产配置缺失时拒绝启动。

## 尚未实现

- 镜像/套餐/价格的管理 API 与超级管理台页面。
- 订单创建、人工收款确认、资源预占、续费和到期策略。
- RabbitMQ 消费者执行 agent 操作、任务重试、死信与状态回写。
- 节点心跳、容器状态同步、审计日志写入、监控和告警。

因此现阶段仅适合开发和部署联调，不应作为收费服务上线。
