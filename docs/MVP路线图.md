# 首发 MVP 路线图

## 首发业务规则

- 单裸机首发，默认可售资源为 16 核 / 256 GB，后续预留多节点。
- 套餐按月收费，金额以分存储；人工确认付款后才部署。
- 未付款订单不预占资源；确认付款时事务校验容量。
- 到期或删除后停止容器并保留数据 7 天，再执行清理。

## 实施顺序

1. **控制面**：节点、镜像摘要、套餐、平台总配额与管理员配置页面。
2. **交易**：商品目录、订单、付款备注、确认/拒绝、续费与过期状态。
3. **任务**：持久化任务、RabbitMQ 执行器、重试、状态同步和 agent 心跳。
4. **用户体验**：实例操作、访问链接、任务失败原因、到期和续费提示。
5. **运维**：审计、备份恢复、指标、告警、TLS/DNS 验收和端到端测试。

## 上线门槛

- 不允许用户传入任意镜像；必须选择后台已启用且固定摘要的镜像版本。
- 资源预占必须并发安全，任何订单都不能突破节点总配额。
- 服务重启后订单、实例和任务必须从 MySQL 恢复；生产环境不得使用内存回退。
- 实例无宿主机端口映射，泛域名 TLS、Nginx 路由与 agent 内网代理均通过验收。
