# 超级管理台

超级管理台仅向 Auth 中拥有 `cloud:admin` 权限的用户开放。其目标是控制首发单裸机的可售资源、镜像、套餐、订单与任务风险。

> 当前状态：MySQL 表结构已预留；管理 API 与前端页面待实现。

## 首发管理项

| 模块 | 默认值或规则 | 作用 |
|---|---|---|
| 节点资源 | 16 核 / 256 GB | 创建已确认订单时不能超过总配额 |
| Agent | 单个内网地址 | 保存健康状态与最后心跳时间 |
| 镜像版本 | 镜像引用 + 不可变摘要 | 只允许已启用镜像进入部署任务 |
| 套餐 | CPU、内存、月价、排序、启用状态 | 用户只能购买已上架套餐 |
| 订单 | 待支付、待确认、已拒绝、部署中、已生效、已到期、已取消 | 管理员以付款备注/流水确认人工收款 |
| 任务 | 创建、启动、停止、删除、清理 | 查看尝试次数、失败原因和重试状态 |

## 资源规则

- 未付款订单不占资源。
- 确认付款时，在同一数据库事务中锁定节点配额、写入预占和创建部署任务。
- 资源不足时不得确认订单，应提示用户联系官方客服。
- 到期或用户删除时先停止容器；数据卷保留 7 天后由清理任务移除。

## 安全边界

- 管理员不能在页面中输入任意 Docker 参数或镜像地址。
- Agent 令牌只能通过受保护配置管理，不显示在页面和审计日志中。
- 关键操作写入审计日志，包含操作者、目标、动作和时间，不记录会话令牌或敏感订单内容。
