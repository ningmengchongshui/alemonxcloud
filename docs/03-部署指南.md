# 部署指南

## 1. 准备依赖

准备 Linux、Docker Engine、Docker Compose、Nginx、systemd，以及带持久化和备份的 MySQL、Redis、RabbitMQ。DNS 需要主站域名和实例泛域名；TLS 证书必须覆盖实例泛域名。

## 2. 配置控制面

复制 `.env.example` 为 `.env`，至少填写：

```dotenv
GIN_MODE=release
PUBLIC_URL=https://xcloud.alemonjs.com
AUTH_OIDC_ISSUER=https://auth.alemonjs.com
AUTH_OIDC_CLIENT_ID=<OIDC客户端ID>
AUTH_OIDC_REDIRECT_URL=https://xcloud.alemonjs.com/callback
MYSQL_DSN=<MySQL连接串>
SESSION_REDIS_URL=<Redis连接串>
RABBITMQ_URL=<RabbitMQ连接串>
XCLOUD_NODE_TOKEN_ENCRYPTION_KEY=<base64编码的32字节密钥>
XCLOUD_METRICS_TOKEN=<监控令牌>
XCLOUD_INSTANCE_DOMAIN=alemonjs.com
XCLOUD_INSTANCE_DATA_ROOT=/var/lib/xcloud/instances
```

生成密钥：`openssl rand -base64 32`。Agent 地址和 Agent 令牌只在超级管理台登记，不写进控制面环境变量。

## 3. 启动控制面

```bash
docker compose up -d --build
docker compose ps
curl http://127.0.0.1:13082/healthz
curl http://127.0.0.1:13082/readyz
```

首次启动会执行数据库迁移；上线前在管理台核对镜像摘要、套餐和节点配额。

## 4. 安装 Agent

按 [Agent 节点](04-Agent节点.md) 安装至少一个节点，并登记到超级管理台。

## 5. 配置 Nginx

- 主站使用 `deploy/nginx-xcloud-server.conf`，代理到 `127.0.0.1:13082`。
- 实例域名使用 `deploy/nginx-instance-proxy.conf`，代理到控制面实例路由入口。
- 补齐 443 TLS 证书，并把 80 重定向到 443。

## 6. 防火墙与验证

仅允许控制面 Compose 网段 `172.30.0.0/24` 和本机访问 Agent 的 13092。发布后必须实际演练登录、钱包购买、余额/容量不足拒绝、部署、钱包续费、域名访问、到期停止和 7 天清理，并确认用户容器没有宿主机端口映射。
