# 管理与运营

超级管理台只对 Auth 具备 `cloud:admin` 权限的用户开放。

## 推荐操作顺序

1. “镜像”：登记可信镜像来源；系统会创建 `latest` 草稿。按需新增版本标签后执行“同步并发布”：所有健康节点拉取并返回一致的不可变 `sha256` 摘要后，版本才可售。
2. “套餐”：配置 CPU、内存、月价（整数分）、排序和启用状态。
3. “节点”：登记 Agent 地址、令牌、CPU、内存并确认心跳正常。
4. “订单”：查看钱包自动购买与部署结果，无需人工确认收款。
5. “任务”：查看部署状态；失败时确认原因后重试。
6. “工单管理”：优先处理紧急和高优先级工单，回复后可标记处理中或关闭。
7. “审计日志/指标”：检查关键操作、资源情况和未关闭工单。

## 关键规则

- 钱包购买和续费在事务中锁定钱包；新购会同时锁定节点、核验容量并创建任务。余额或容量不足时不会扣款。
- 只有后台已发布且启用的镜像版本和套餐可以下单；用户不能提交任意镜像地址、标签或 Docker 参数。订单始终固化已验证的 digest。
- 钱包流水不可编辑；管理员充值、扣减、购买、续费和退款均留下独立流水，并通过订单 ID 关联。冲正使用新的负向流水。
- 节点离线后不参与新订单，已有实例不自动迁移。
- 用户退款只退回 XCoin，不接外部支付退款；退款不会立即停止实例，预扣 3 天服务期，停止后数据保留 30 天。历史订单和服务期异常订单由用户提交工单，管理员按账本人工处理。
- 普通到期或删除先停止实例，数据保留 7 天后清理；退款实例会在清理前约 7 天和 1 天收到站内提醒。
- 工单支持实例与部署、账务与续费、账号与访问及其他问题；用户关闭后可重新打开，消息与操作记录不可编辑。

金额以整数分保存，100 分为 1 元/1 代币。节点令牌由 `XCLOUD_NODE_TOKEN_ENCRYPTION_KEY` 加密保存；更换该密钥前必须制定重新加密方案。
