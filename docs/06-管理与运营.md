# 管理与运营

超级管理台只对 Auth 具备 `cloud:admin` 权限的用户开放。

## 推荐操作顺序

1. “镜像”：登记镜像来源和不可变 `sha256` 摘要并启用。
2. “套餐”：配置 CPU、内存、月价（整数分）、排序和启用状态。
3. “节点”：登记 Agent 地址、令牌、CPU、内存并确认心跳正常。
4. “订单”：查看钱包自动购买与部署结果，无需人工确认收款。
5. “任务”：查看部署状态；失败时确认原因后重试。
6. “审计日志/指标”：检查关键操作和资源情况。

## 关键规则

- 钱包购买和续费在事务中锁定钱包；新购会同时锁定节点、核验容量并创建任务。余额或容量不足时不会扣款。
- 只有后台启用的镜像和套餐可以下单；用户不能提交任意镜像地址或 Docker 参数。
- 钱包流水不可编辑；管理员充值、扣减、购买和续费均留下独立流水，冲正使用新的负向流水。
- 节点离线后不参与新订单，已有实例不自动迁移。
- 到期或删除先停止实例，数据保留 7 天后清理。

金额以整数分保存，100 分为 1 元/1 代币。节点令牌由 `XCLOUD_NODE_TOKEN_ENCRYPTION_KEY` 加密保存；更换该密钥前必须制定重新加密方案。
