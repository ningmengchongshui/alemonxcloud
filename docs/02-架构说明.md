# 架构说明

## 组件

```text
浏览器 ─HTTPS→ Nginx ─HTTP→ xcloud-server:8082
                             ├─ MySQL：业务数据
                             ├─ Redis：登录会话
                             ├─ RabbitMQ：部署任务
                             └─ Agent:13092 ─Docker→ ALemonX:17390
```

Compose 将主应用的宿主端口 `13082` 映射到容器端口 `8082`。主站 Nginx 代理到 `127.0.0.1:13082`。

## 请求链路

1. Auth 使用 OIDC Authorization Code + PKCE 登录，服务端以 HttpOnly 会话保存状态。
2. 用户下单后，控制面校验商品、余额和节点容量。
3. 订单确认事务锁定节点并创建实例、预占记录和部署任务。
4. RabbitMQ 消费者调用 Agent，Agent 在 `xcloud_network` 中创建容器。
5. 用户通过随机路由域名访问实例，实例不暴露宿主机端口。

## 状态与生命周期

- 订单：待支付、待确认、已拒绝、部署中、已生效、已到期、已取消。
- 任务：queued、running、retrying、failed、succeeded。
- 节点：online、offline、disabled。

实例采用两阶段销毁：退款按退款后的最终服务时间、正常到期和手动销毁在 7 天等待期后销毁容器资源；数据目录随后再保留 30 天，最后由清理任务物理删除。
