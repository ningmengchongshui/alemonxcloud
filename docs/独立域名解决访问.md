# 独立域名访问

每个实例使用单一、不可读的路由域名：

```text
https://xcloud-r<16位十六进制哈希>.alemonjs.com
```

路由键由服务端根据用户与实例生成，并作为 Docker 标签 `xcloud.route` 写入容器。它不包含用户 ID、设备 ID 或容器名。

```text
浏览器 → 泛域名 TLS Nginx → 127.0.0.1:13092 agent
       → Docker 标签查询 → docker inspect 内网 IP → 实例 :17390
```

Nginx 只注入 `X-Route-Key`，agent 校验格式后移除该请求头再反代。因此用户容器不会收到路由内部信息，也不需要映射宿主机端口。

## 必要配置

- DNS：`*.alemonjs.com` 指向 Nginx 所在服务器。
- TLS：证书必须覆盖 `*.alemonjs.com`。
- Nginx：使用 `deploy/nginx-instance-proxy.conf`，将请求转发到本机 agent 的 13092 端口。
- Docker：创建 `xcloud_network`；容器必须加入该网络。
- 防火墙：13092 不对公网开放。

若 Nginx 与 agent 不在同一宿主机，不能直接复用当前示例；必须建立受限内网连通性，并限制只有 Nginx 可访问 agent。
