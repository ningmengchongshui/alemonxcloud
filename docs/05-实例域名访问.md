# 实例域名访问

实例地址格式：

```text
https://xcloud-r<16位十六进制路由键>.<XCLOUD_INSTANCE_DOMAIN>
```

路由键由服务端生成，不包含用户 ID、设备 ID 或容器名，并作为 Docker 标签 `xcloud.route` 保存。

## 流程

```text
浏览器 → 泛域名 TLS Nginx → 控制面路由入口
       → 按路由键选择节点 → Agent → Docker 内网 IP:17390
```

Nginx 传递 `X-Route-Key`；控制面和 Agent 校验后移除该请求头再反代。用户容器不映射宿主机端口。

## 必须满足

- DNS 泛域名指向 Nginx。
- TLS 证书覆盖泛域名。
- 使用 `deploy/nginx-instance-proxy.conf` 并改成实际域名。
- 所有 Agent 加入 `xcloud_network`。
- Agent 13092 不对公网开放。
