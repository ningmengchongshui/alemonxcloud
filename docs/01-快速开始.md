# 快速开始

## 本地开发

```bash
cp .env.example .env
cd frontend && yarn
cd .. && make dev
```

另开终端执行 `make dev-fe`，打开 `http://localhost:5173`。开发模式使用 `/api/dev/login` 登录；生产模式禁用该入口。

检查服务：

```bash
curl http://localhost:8082/healthz
make test
make lint
make build-fe
```

## 业务主流程

```text
登录 → 选择镜像和套餐 → 创建订单 → 提交付款凭证
→ 管理员确认收款 → 锁定节点资源 → 创建部署任务
→ Agent 创建容器 → 访问实例域名
```

付款是人工确认；任务失败会有限重试，管理员可在管理台重试。需要联调实例时，先创建 `xcloud_network`，再按 [Agent 节点](04-Agent节点.md) 配置并运行 Agent。
