# 前端体验治理

## 产品原则

ALemonX Cloud 是开发者自助云平台。所有界面优先回答三个问题：现在能做什么、系统正在做什么、下一步该做什么。用户控制台只展示用户资源与订单；超级管理台只展示运营、供给和合规能力。

## 设计评审清单

- 页面必须有明确任务标题、简短说明和一个主要操作。
- 默认、加载、空数据、错误、禁用、提交中和完成反馈必须完整。
- 窄屏使用线性阅读顺序；复杂表格保留横向滚动和可触达的操作入口。
- 状态必须有文字和图形提示，不能只用颜色。
- 弹窗支持键盘焦点、Esc、遮罩关闭和关闭后的焦点恢复。
- 深色模式、200% 缩放和键盘操作属于发布验收项。

## 匿名体验事件

`POST /api/telemetry/console-events` 仅接收事件名、工作区、页面、粗粒度动作、结果、耗时和视口类别。禁止提交用户、订单、实例、节点标识、表单输入、日志、令牌和其他可识别内容。

每月查看创建服务完成率、创建失败结果、部署状态停留时长、续费完成率、关键管理操作错误率及移动端完成率；数据只用于产品体验改进。

## 发布门槛

前端变更至少执行 `yarn lint`、`yarn build` 和关键路径交互验收；后端接口变更执行 `go test ./src`。新增组件优先复用 `frontend/src/components/ui.tsx`，避免重复定义按钮、状态、加载、空状态和对话框行为。
