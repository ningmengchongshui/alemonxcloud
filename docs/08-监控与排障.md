# 监控与排障

## 检查顺序

```bash
docker compose ps
curl http://127.0.0.1:13082/healthz
curl http://127.0.0.1:13082/readyz
systemctl status xcloud-agent
curl http://127.0.0.1:13092/healthz
```

## 指标与告警

`/metrics` 需要 `Authorization: Bearer $XCLOUD_METRICS_TOKEN`，只允许监控网段访问。可导入 `deploy/prometheus-alerts.yml`。重点关注依赖不可用、Agent 心跳超时、任务积压/失败、实例健康失败和磁盘剩余空间低于 15%。

| 现象 | 优先检查 |
|---|---|
| `/readyz` 失败 | `.env` 连接串、依赖网络、Agent 地址和令牌 |
| Agent 超时 | 防火墙、`172.30.0.0/24`、systemd 状态、13092 监听 |
| 域名打不开 | DNS、泛域名证书、Nginx 配置、路由键格式 |
| 任务失败 | 任务错误、RabbitMQ、镜像摘要和 Agent 日志 |
| 节点不能接单 | 90 秒心跳、节点是否 disabled、可用配额 |

排障时保留任务 ID、实例 ID、节点 ID 和时间；不要复制令牌或 Cookie。
